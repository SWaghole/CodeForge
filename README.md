CodeForge – Campus Skill Sharing Platform

CodeForge is a Java-based web application designed to strengthen peer-to-peer coding collaboration within a college campus. The platform enables students to discover coding communities, connect with peers based on technical skills, and participate in focused learning sessions.

It bridges the gap between theoretical learning and practical development by creating structured coding circles and real-time interaction spaces.

📌 Features

👩‍🎓 Student Module

User registration & authentication  
Profile creation with skills and interests  
Discover coding communities using filters (tech stack, skill level)  
Join coding circles  
Real-time peer interaction  
Manage joined communities  

🛠 Admin Module

Admin login & dashboard  
Manage users and communities  
Remove inactive or spam accounts  
Moderate interactions  
Update homepage content  

🧑‍💻 Tech Stack

Layer | Technology  
Backend | Spring Boot  
Security | Spring Security (Role-Based Access Control)  
API | RESTful Web Services  
ORM | Spring Data JPA / Hibernate  
Database | MySQL  
Build Tool | Maven  
IDE |IntelliJ IDEA
Architecture | Layered Architecture  

🏗 System Architecture

Controller Layer – REST APIs  
Service Layer – Business Logic  
Repository Layer – Database Operations  
Data Layer – MySQL  

🎯 Objectives

Enable students to discover coding peers easily  
Promote collaborative learning  
Provide structured coding communities  
Improve practical technical exposure  

💡 Problem Solved

Traditional platforms like WhatsApp groups or college forums are unstructured for technical collaboration. CodeForge provides a dedicated environment for skill-based peer learning with organized communities and searchable profiles.
